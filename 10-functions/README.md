# Functions

## 🇺🇸 English

This chapter introduces functions in Python.

Topics include defining functions, passing arguments, returning values, default arguments, keyword arguments, variable-length arguments, lambda functions, `map()`, `filter()`, `reduce()`, recursion, variable scope, the `global` keyword, and common built-in functions.
